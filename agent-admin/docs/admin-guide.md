# Agent Admin 管理员使用说明

本文面向平台管理员，用于管理代理商、客户归属、分成、结算和登录安全设置。

## 1. 登录

管理员使用与 sub2api 原系统一致的账号密码登录 Agent Admin。

要求：

- 账号必须是 sub2api 原系统中的管理员账号。
- Agent Admin 的 `JWT_SECRET` 和签名算法需要与 sub2api 保持一致。
- 如果 sub2api 启用了 Turnstile，Agent Admin 设置页中的 Site Key 也应配置为同一套 Turnstile Site Key。

登录后进入“工作台”，可以查看代理总数、有效代理、周期确认收入和可结算金额。

## 2. 系统设置

入口：`系统设置`

当前支持登录安全设置：

- `启用 Turnstile`：开启后，Agent Admin 登录页会展示 Cloudflare Turnstile 校验组件。
- `Site Key`：填写 Cloudflare Turnstile Site Key。

注意：

- Secret Key 和实际校验仍由 sub2api 原系统负责。
- Agent Admin 设置页只控制登录页是否展示 Turnstile，以及使用哪个 Site Key。
- Site Key 应与 sub2api 原系统 Turnstile 配置保持一致。

## 3. 指定代理商

入口：`代理管理` -> `指定代理`

管理员可以从原系统用户中指定代理商。

需要填写：

- `用户邮箱`：输入原 sub2api 用户邮箱或用户名进行搜索。
- `选择用户`：从搜索结果中选择要指定为代理商的用户。
- `代理等级`：1 级、2 级或 3 级。
- `上级代理`：2 级和 3 级代理必选，系统会按等级过滤可选上级。
- `比例 %`：可选；不填时使用默认比例。

默认比例：

- 1 级代理：20%
- 2 级代理：15%
- 3 级代理：10%

规则：

- 1 级代理不能设置上级。
- 2 级代理必须选择 1 级代理作为上级。
- 3 级代理必须选择 2 级代理作为上级。
- 一个原系统用户只能拥有一个代理身份。
- 下级代理比例必须低于上级代理比例。

## 4. 管理代理列表

入口：`代理管理` -> `代理列表`

列表展示：

- 代理账号
- 代理等级
- 上级代理
- 当前分成比例
- 客户数量
- 可结算金额
- 状态

可执行操作：

- 修改代理比例。
- 禁用代理。
- 恢复代理。
- 填写“强制调整原因”后进行带审计记录的强制调整。

禁用代理的含义：

- 代理身份保留。
- 历史客户、分成和结算记录保留。
- 禁用期间不能作为有效代理继续产生新的代理业务权限。
- 后续可由管理员恢复。

## 5. 客户归属

入口：`客户归属`

管理员可以手动把指定客户归属给指定代理商。

需要填写：

- `客户账号`：输入原 sub2api 用户邮箱或用户名进行搜索。
- `选择客户`：从搜索结果中选择要归属的客户。
- `目标代理`：选择目标代理商。
- `调整原因`：必填，用于审计。

生效规则：

- 一个客户同一时间只能归属一个代理。
- 手动归属默认从客户下一个完整套餐周期开始生效。
- 如果客户当前没有未结束套餐周期，则可立即生效。
- 手动归属优先于自然推荐同步。
- 不会默认写回 sub2api 原推荐系统。

页面中的“客户列表”用于按代理查看客户归属、来源、套餐、周期结束时间、周期确认收入和状态。

页面中的“归属变更记录”用于查看管理员调整原因、原代理、目标代理、操作人和生效时间。

## 6. 分成记录

入口：`分成记录`

分成记录由定时任务生成。系统会扫描已完成且到达套餐周期结束时间的订单，并按客户归属和当时生效比例生成分成。

列表展示：

- 客户
- 订单
- 套餐周期
- 确认收入
- 分成比例
- 分成金额
- 冲正金额
- 状态

分成计算基准：

- 以套餐周期结束时的订单实付金额为准。
- 金额按最小货币单位保存，页面展示为元。
- 多级代理采用差额分成。

差额分成示例：

- 客户周期确认收入 1000 元。
- 1 级代理比例 20%。
- 2 级代理比例 15%。
- 3 级代理比例 10%。
- 客户归属 3 级代理时：3 级拿 100 元，2 级拿 50 元，1 级拿 50 元。

## 7. 结算记录

入口：`结算记录`

管理员可以查看全局结算记录，并执行结算处理。

结算规则：

- 最低结算金额：100 元。
- 冻结时间：5 天。
- 结算周期：自然月月底结算。

列表展示：

- 代理
- 月份
- 金额
- 冲正
- 净额
- 冻结至
- 支付时间
- 状态

管理员可执行：

- 对 `可结算` 状态记录标记已支付。
- 调整冲正金额。
- 调整结算状态。
- 填写调整原因并保存。

冲正来源：

- 后续退款。
- 管理员账务修正。
- 历史订单或归属异常导致的修正。

负数冲正可以结转抵扣后续分成。

## 8. 代理经营

入口：`代理经营`

管理员也可以查看代理经营相关页面，但该页面主要面向代理商。

可查看：

- 推荐用户。
- 下级代理。
- 直接客户订单。

管理员处理代理商问题时，优先使用：

- `代理管理` 进行代理身份、等级、上级、比例、禁用恢复调整。
- `客户归属` 进行客户归属修正。
- `结算记录` 进行账务修正。
- `审计日志` 追踪历史操作。

## 9. 审计日志

入口：`审计日志`

审计日志记录关键管理操作：

- 指定代理。
- 调整代理等级。
- 调整上级代理。
- 调整分成比例。
- 客户归属调整。
- 禁用或恢复代理。
- 结算账务调整。
- 系统设置调整。

建议所有运营纠纷处理完成后，管理员在审计日志中确认操作记录是否完整。

## 10. 常见问题

### 代理登录失败

检查：

- 代理是否使用原系统账号密码。
- 用户在原系统是否为 active。
- 该用户是否已经被指定为代理。
- 代理状态是否为 active。
- Agent Admin 的 JWT 配置是否与 sub2api 一致。

### Turnstile 校验失败

检查：

- sub2api 原系统是否启用了 Turnstile。
- Agent Admin 设置页是否启用了 Turnstile。
- Site Key 是否与 sub2api 配置一致。
- Cloudflare Turnstile 域名配置是否包含 Agent Admin 当前访问域名。

### 客户归属保存后没有立即变化

这是预期行为。手动归属默认从客户下一个完整套餐周期生效，当前周期仍按原归属计算。

### 分成记录没有出现

检查：

- 订单是否已完成。
- 套餐周期是否已经结束。
- 客户是否已有 active 代理归属。
- Agent Admin 定时任务是否启用。
