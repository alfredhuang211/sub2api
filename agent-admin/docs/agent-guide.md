# Agent Admin 代理商使用说明

本文面向代理商，用于查看客户、可发展用户、下级代理、分成和结算记录。

## 1. 登录

代理商使用与 sub2api 原系统一致的账号密码登录 Agent Admin。

要求：

- 你的原系统账号已由管理员指定为代理商。
- 代理状态为 active。
- 如果登录页出现 Turnstile 校验，请先完成校验再登录。
- 如果账号启用了两步验证，需要按页面提示输入验证码。

普通用户未被管理员指定为代理商前，不能使用代理商功能。

## 2. 工作台

入口：`工作台`

工作台展示两个视角：

- 平台汇总：代理总数、有效代理、周期确认收入、可结算金额。
- 我的代理身份：账号、等级、上级代理、状态。
- 我的经营汇总：直接客户、下级代理、分成金额、冲正金额。

2 级和 3 级代理可以在“我的代理身份”中看到自己的上级代理账号。

## 3. 我的客户

入口：`客户归属` 或相关客户列表

代理商可以查看直接归属自己的客户。

客户信息包括：

- 客户账号。
- 来源。
- 套餐。
- 周期结束时间。
- 周期确认收入。
- 状态。

来源说明：

- `自然推荐`：客户来自原系统推荐关系。
- `管理员归属`：客户由管理员手动设置给代理商。

客户同一时间只能归属一个代理。

## 4. 可发展用户

入口：`代理经营` -> `我的可发展用户`

这里展示直接归属于你的用户，可用于创建下级代理。

来源包括：

- `自然推荐`：用户通过你的原系统推荐码引入。
- `管理员归属`：管理员在客户归属中手动指定给你。

可发展用户必须满足：

- 用户直接归属于你，归属状态为有效或待生效。
- 你当前等级允许继续发展下级。
- 该用户尚未成为其他代理。

3 级代理不能继续创建下级代理。

## 5. 创建下级代理

入口：`代理经营` -> `创建下级代理`

可填写：

- `可发展用户`：从你的可发展用户中选择要指定为下级代理的账号。
- `比例 %`：可选；不填时使用默认比例。

层级规则：

- 1 级代理可以创建 2 级代理。
- 2 级代理可以创建 3 级代理。
- 3 级代理不能创建下级代理。

比例规则：

- 下级代理比例必须低于你的比例。
- 比例允许为 0%。
- 默认比例为 2 级 15%、3 级 10%。

如果创建失败，通常原因是：

- 用户不是直接归属于你的可发展用户。
- 用户已经是代理。
- 你的代理等级不允许继续创建下级。
- 设置的比例不低于你的比例。

## 6. 我的下级代理

入口：`代理经营` -> `我的下级代理`

你可以查看直属下级代理：

- 账号。
- 等级。
- 分成比例。
- 客户数量。
- 状态。

你可以调整直属下级代理比例。保存时需要满足下级比例低于你的比例。

## 7. 我的客户订单

入口：`代理经营` -> `我的客户订单`

这里只读展示直接客户订单。

订单信息包括：

- 订单号。
- 客户账号。
- 金额。
- 支付时间。
- 完成时间。
- 状态。

订单用于后续按套餐周期生成分成记录。不是所有支付完成的订单都会立即产生分成，需要等套餐周期结束。

## 8. 分成记录

入口：`分成记录`，切换到 `代理商`

分成记录展示你可获得的周期分成。

字段说明：

- `客户`：产生消费的客户。
- `订单`：对应订单。
- `周期`：套餐周期开始和结束时间。
- `确认收入`：周期结束时确认的订单实付金额。
- `比例`：计算该笔分成时使用的比例。
- `分成`：该周期应得金额。
- `冲正`：退款或账务修正产生的抵扣金额。
- `状态`：冻结中、可结算、已结算等。

分成不会在客户支付后立即确认，而是在客户的套餐周期结束后统计。

## 9. 结算记录

入口：`结算记录`，切换到 `代理商`

结算记录展示你的自然月结算情况。

结算规则：

- 最低结算金额：100 元。
- 冻结时间：5 天。
- 结算周期：自然月月底结算。

字段说明：

- `月份`：结算归属月份。
- `金额`：当月分成总额。
- `冲正`：退款或账务修正抵扣。
- `净额`：扣除冲正后的金额。
- `冻结至`：资金冻结结束时间。
- `结算登记`：管理员线下付款后的登记信息，可能包含付款金额、支付方式、支付时间、流水号、备注和登记人。
- `状态`：当前结算状态。

如果净额未达到最低结算金额，会继续等待后续周期累计或抵扣。

## 10. 分成计算说明

多级代理采用差额分成。

示例：

- 客户周期确认收入 1000 元。
- 1 级代理比例 20%。
- 2 级代理比例 15%。
- 3 级代理比例 10%。

如果客户归属 3 级代理：

- 3 级代理获得 100 元。
- 2 级代理获得 50 元。
- 1 级代理获得 50 元。

如果客户归属 2 级代理：

- 2 级代理获得 150 元。
- 1 级代理获得 50 元。

如果客户归属 1 级代理：

- 1 级代理获得 200 元。

整条链路总分成不超过最高上级代理比例。

## 11. 常见问题

### 我无法登录 Agent Admin

请联系管理员确认：

- 你的原系统账号是否正常。
- 你是否已被指定为代理商。
- 代理状态是否为 active。

### 我看不到某个客户

可能原因：

- 客户尚未通过你的推荐码形成关系。
- 管理员已将客户手动归属给其他代理。
- 手动归属设置了下个套餐周期生效，当前周期还未切换。

### 我推荐的用户不能创建为下级代理

可能原因：

- 该用户不是通过你的推荐码引入。
- 该用户已经是代理。
- 你是 3 级代理，不能继续发展下级。
- 设置给下级的比例不符合规则。

### 客户已经付款，为什么没有分成

分成按套餐周期结束后确认，不是付款后立即确认。请等待该客户套餐周期结束，并确认订单状态已完成。

### 结算金额为什么被冲正

冲正通常来自退款、账务修正或历史异常修正。冲正金额会抵扣当前或后续分成。
